The product decisions originate in the supplied project conversation. Branding colors, dimensions and hashes were inspected directly from the provided archive. No private user health data was used as a test fixture.

Each specification links only the references relevant to its factual technical statements. Design choices, limits, algorithms and acceptance criteria are Vulpes proposals unless explicitly attributed.
