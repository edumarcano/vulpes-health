Vulpes brand assets

Contents
- core-logos/: primary approved logo assets
- stacked-logos/: stacked versions for profile/repo/vertical placements
- app-icons/: main 1024x1024 app icon variants
- favicons/: square favicon exports from the color icon (512 down to 16)
- monochrome/: one-color logo/symbol variants
- proofs/: review sheets
- source-extractions/: extracted source elements used to assemble the approved assets

Notes
- Favicons at 32x32 and especially 16x16 will naturally look softer or blurrier because of the very small pixel dimensions.
- The core approved masters for this package are the files in core-logos/ and app-icons/.
