## Implemented preparation

Its candidate namespace preserves the historical v0.1.0 map and reports. Records bind the source revision, source/workspace digests, candidate, configuration/content versions and acceptance-map hash. The versioned command excludes retained reset and the historical empty-stack upgrade.
